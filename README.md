## Tentang Saya

Saya mahasiswa Teknik Informatika yang senang membangun sesuatu dari nol sampai benar-benar bisa dipakai orang — mulai dari antarmuka web yang rapi dan interaktif, sampai fitur cerdas yang ditenagai AI/Machine Learning di baliknya.

Belakangan fokus saya makin condong ke sisi produk: membangun platform dan sistem (SaaS, otomasi, dashboard bisnis) yang bukan cuma jadi proyek belajar, tapi punya potensi dipakai secara nyata. Saya terbiasa kerja dalam tim, komunikatif, dan senang ambil bagian dari perencanaan arsitektur sampai eksekusi teknis.
